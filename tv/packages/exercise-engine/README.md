# @projectplay/exercise-engine

The offline question engine behind the game: addition, subtraction and missing-addend questions with misconception-based wrong answers, `diagnose()` for the reason behind a wrong pick, and class-level adaptive difficulty.

It is also published on its own as **[projectplay-exercise-engine](https://github.com/binnicordova/projectplay-exercise-engine)** (MIT), with full docs, examples and CI. That repository is the source of truth; this folder keeps a copy of its `src/` so the TV apps build without a network fetch. Change both together.
